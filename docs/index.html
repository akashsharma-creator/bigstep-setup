Bigstep PC Setup

Installs the standard Bigstep software — always the latest versions. You choose which apps before anything is installed.

✓ Detected: this is a Windows PC

Windows 10 / 11

  1. Click Start, type PowerShell and open Windows PowerShell.
  2. Click Copy, then right-click inside the PowerShell window to paste, and press Enter: 
    irm https://raw.githubusercontent.com/akashsharma-creator/bigstep-setup/main/windows/setup.ps1 | iex
  3. Click Yes on the “allow this app to make changes” prompt.
  4. In the choose software window, tick the apps you want and click Install.
  5. Wait for the SUMMARY table (10–30 min), press Enter, then restart the PC.

Apps that are already installed are upgraded to the latest version. A log is saved in C:\BigstepSetup\.

✓ Detected: this is a Mac

macOS

  1. Press ⌘ Cmd + Space, type Terminal and press Enter.
  2. Click Copy, paste into Terminal with ⌘ Cmd + V, and press Enter: 
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/akashsharma-creator/bigstep-setup/main/macos/setup.sh)"
  3. In the Bigstep Mac Setup window, select the apps you want (⌘ Cmd-click to pick several) and click Install.
  4. Type your Mac login password when asked (nothing appears while you type — that's normal) and press Enter.
  5. Wait for the SUMMARY, then restart the Mac.

The script detects whether this Mac has an Intel or Apple M-series chip and downloads the latest version of each app for that chip. Apps that are already installed are upgraded. A log is saved in ~/BigstepSetup/.
